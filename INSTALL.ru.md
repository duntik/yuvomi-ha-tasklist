# Установка Yuvomi Tasklist

Это экспериментальная версия. Начни с тестовых задач.

1. Открой **HACS → меню ⋮ → Пользовательские репозитории**.
2. Добавь `https://github.com/duntik/yuvomi-ha-tasklist`, тип **Integration**.
3. Найди **Yuvomi Tasklist**, скачай и перезапусти Home Assistant.
4. В Yuvomi открой **Настройки → API Tokens** и создай токен с правами
   `tasks:write`. Токен никому не отправляй.
5. В HA открой **Настройки → Устройства и службы → Добавить интеграцию**,
   выбери **Yuvomi Tasklist**. Введи адрес Yuvomi, токен и часовой пояс,
   совпадающий с часовым поясом семьи в Yuvomi.
6. Обнови вкладку браузера. В обычном разделе **Списки дел** выбери
   **Yuvomi Tasks**.

Открой задачу — появится редактор с приоритетом, категорией, исполнителями,
повторениями и подзадачами. Кнопка **Yuvomi · фильтры и архив** в обычном
разделе списков открывает поиск, фильтры и архив.

Дополнительный контейнер Proxmox и настройка карточек не нужны.

Если расширенный редактор мешает или перестал работать после обновления HA,
открой настройки интеграции, выключи **Расширить встроенный To-do**, затем
обнови вкладку браузера. Стандартный список продолжит работать.

Без HACS: распакуй `yuvomi.zip` из Releases, скопируй папку `yuvomi` в
`/config/custom_components/`, перезапусти HA и продолжи с шага 4.

Совместимость backend проверяется в CI с HA 2026.9.4. На реальной установке
пока не проверено. Комментарии, вложения, история и напоминания ещё не добавлены.
